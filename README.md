# World News — Saturday 21 November 2026

A single 1024×1024 PNG poster with six verified world-news stories from
Saturday 21 November 2026, laid out in a 2-column × 3-row grid under the
headline **"WORLD NEWS — SATURDAY 21 NOVEMBER 2026"**.

## How to run

```sh
python3 main.py
```

This writes `entry.png` (1024×1024, RGB) into the same directory.
Python standard library only — no third-party dependencies.

The program is fully deterministic: running it twice produces a
byte-identical PNG (same SHA-256). It contains its own 5×7 bitmap font
and its own PNG encoder, so it needs nothing but a Python 3 interpreter.
